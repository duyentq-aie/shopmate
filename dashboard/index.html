Định dạng trace để nối dữ liệu thật

Mỗi request là một dòng JSON trong logs/traces.jsonl. Tải file đó lên bằng nút “Tải file trace”: mọi số trên trang được tính lại trong trình duyệt, không gửi đi đâu. Chi phí tính từ token và giá ở cột bên trái; span có cache_hit: true không tính tiền.

Chế độ trực tiếp: khi ShopMate phục vụ chính trang này (ví dụ http://127.0.0.1:8765/monitor/) và có GET api/traces?limit=5000 trả về các dòng JSONL cuối file, trang tự chuyển sang “TRỰC TIẾP” và làm mới mỗi 5 giây.
